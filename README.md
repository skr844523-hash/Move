# Sticker ZIP 📦

تطبيق ويب عربي يحوّل رابط حزمة ملصقات تيليجرام إلى ملف ZIP يحتوي على الملصقات الفعلية.

## كيف يعمل
- **الواجهة** (`public/`): HTML + CSS + JS خالصة، وكاتب ZIP مكتوب يدويًا (بدون مكتبات).
- **الخادم** (`lib/`, `api/`, `server.js`): وسيط صغير يستدعي Telegram Bot API باستخدام توكن البوت، لأن التوكن سري ولا يجوز وضعه في المتصفح.
- لا قاعدة بيانات، لا تسجيل دخول، لا Firebase، ولا أي حزم npm.

## المتطلبات التي لا غنى عنها
1. **توكن بوت تيليجرام** (مجاني): من `@BotFather` ← `/newbot`.
2. **Node.js 18 أو أحدث** للتشغيل المحلي.
3. حساب **Vercel** (مجاني) أو **Render** للنشر.

## التشغيل محليًا
```bash
cp .env.example .env      # ثم ضع BOT_TOKEN داخل .env
npm start                 # افتح http://localhost:3000
npm test                  # اختبار تلقائي بخادم تيليجرام وهمي
```

## النشر على GitHub + Vercel
1. أنشئ مستودعًا على GitHub وارفع المشروع (ملف `.env` مُستثنى تلقائيًا بـ `.gitignore`).
2. في Vercel: **Add New → Project** واختر المستودع (Framework: Other، بدون أوامر بناء).
3. من **Settings → Environment Variables** أضف `BOT_TOKEN` بقيمة التوكن.
4. اضغط **Deploy** (أو Redeploy بعد إضافة المتغير).

## بديل: Render
**New → Web Service** ← الأمر `node server.js` ← أضف متغير `BOT_TOKEN`.

## الصيغ المدعومة
| النوع | الناتج داخل ZIP |
|---|---|
| ثابت | `.webp` الأصلي، أو `.png` بالتحويل |
| متحرك | `.tgs` الأصلي (تحتاج برنامجًا خارجيًا لتحويله إلى GIF) |
| فيديو | `.webm` الأصلي |

## أمان
- لا تضع التوكن في الكود أو GitHub أبدًا؛ فقط في متغيرات البيئة.
- إن ظهر التوكن في أي مكان عام: `@BotFather` ← `/revoke`.
